Lambda expressions in Java provide a clear and concise way to represent a method interface.
These expressions are used primarily to define the behavior of a method in functional interfaces.
single-line, multiline, and return-type lambda expressions.



Where we can use method reference
if we are taking some parameter and making a function call, or no parameter and just making a function call
Then we can make the code more precise with the user method reference

Method references work only with functional interfaces, which contain exactly one abstract method.

Method signature must match abstract method
A method signature in Java = method name + parameter types (number, type, order)

Common functional interfaces include Consumer, Supplier, Function, Predicate
Used heavily with Streams and Collections
